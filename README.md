# BlazorEventEase
Aplicación EventEase utilizando Microsoft Copilot. Capacitacion COURSERA
Microsoft Copilot me ayudó como asistente de desarrollo durante todo el ciclo de construcción de la solución. Lo utilicé para generar componentes base, resolver errores de compilación, implementar enrutamiento, incorporar validaciones en formularios y diseñar la gestión de estado para las sesiones de usuario.
Gracias a Copilot pude concentrarme más en la lógica de negocio y menos en tareas repetitivas de codificación, además de obtener sugerencias alineadas con las buenas prácticas de Blazor y .NET 10
Me permitió : 
Reutilización de código.
Resolución de errores
implementación del enrutamiento con buenas practicas
Implementar formularios utilizando EditForm y validaciones mediante atributos de Data Annotations
implementar un servicio de sesión desacoplado mediante inyección de dependencias, permitiendo compartir información entre componentes y páginas
Me permitió reforzar lo visto en el Curso, así como visualizar diferentes formas de solventar la lógica de programación.

Copilot tuvo un impacto importante en mi aprendizaje de Blazor .NET 10 porque me permitió aprender mientras desarrollaba. En lugar de buscar documentación para cada duda, podía obtener ejemplos, explicaciones y sugerencias en tiempo real
